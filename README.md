# 🌐 The Web Trio — HTML, CSS & JavaScript

> An interactive, single-page project that explains the **three core languages** of the web — beautifully and visually.

Built entirely with **pure HTML, CSS & JavaScript** — no frameworks, no libraries, just the fundamentals done well.

---

## 📖 What This Project Explains

This page teaches beginners how the web works by breaking it down into three languages, each with its own role:

| Language | Role | What It Does |
| :--- | :--- | :--- |
| 🏗️ **HTML** | **Structure** | Defines *what* is on the page — headings, text, images, links & buttons. The skeleton. |
| 🎨 **CSS** | **Style** | Controls *how* it looks — colors, fonts, spacing, layout & animation. The skin & clothes. |
| 🧠 **JavaScript** | **Behavior** | Controls *what happens* — clicks, logic & dynamic updates. The brain & muscles. |

---

## ✨ Features

Here is everything you'll find inside the page:

- **🎬 Animated Hero Section** — a shimmering gradient title with a smooth "scroll down" hint.
- **📚 Three Detailed Language Cards** — HTML, CSS & JavaScript, each with:
  - A clear description of its purpose
  - A "Why it matters" bullet list
  - A real, syntax-highlighted **code snippet**
- **💡 Analogy Strip** — an easy way to remember each language:
  - HTML = the **skeleton** 🦴
  - CSS = the **skin & clothes** 👕
  - JavaScript = the **brain & muscles** 💪
- **🕹️ Interactive Live Demo** — a box you can change in real time with buttons, plus a click counter — proving all three languages working together.
- **📱 Fully Responsive** — looks great on phones, tablets and desktops.

---

## 🎨 Design Highlights

- Animated moving gradient background
- Floating, glowing decorative blobs
- Glassmorphism (frosted-glass) cards
- Scroll-reveal animations powered by `IntersectionObserver`
- Smooth hover effects and button animations
