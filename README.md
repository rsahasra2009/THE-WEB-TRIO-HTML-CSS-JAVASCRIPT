# The Web Trio — HTML, CSS & JavaScript

An interactive single-page project explaining the three core web languages:
**HTML** (structure), **CSS** (style), and **JavaScript** (behavior).

Built with pure HTML, CSS & JavaScript — no frameworks.

## ✨ Features
- Animated gradient background with floating glow effects
- Glassmorphism cards with scroll-reveal animations
- Interactive live demo (click the buttons!)
- Fully responsive design

## 🚀 Live Demo
https://rsahasra2009.github.io/THE-WEB-TRIO-HTML-CSS-JAVASCRIPT/web-trio.html

## 📂 Files
- `web-trio.html` — the complete page (HTML + CSS + JS in one file)

## 🛠️ Tech Used
- HTML5
- CSS3 (animations, Flexbox, Grid)
- Vanilla JavaScript (IntersectionObserver, DOM events)
