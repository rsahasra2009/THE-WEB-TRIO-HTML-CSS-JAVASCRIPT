HTML Structure

HyperText Markup Language is the skeleton of the web. It defines what content exists on a page — headings, paragraphs, images, links, buttons and more.

Why it matters

  • Meaning, not looks: tags describe content so browsers & search engines understand it.
  • Elements & tags: everything lives inside tags like <h1>, <p>, <a>.
  • Accessibility: semantic tags (<nav>, <article>) help screen readers.
  • The foundation: CSS and JavaScript both attach to HTML elements.
<!-- A simple HTML element -->
<h1>Hello, World!</h1>
<p>I am learning web development.</p>
<a href="#">Follow me</a>

CSS Style

Cascading Style Sheets is the wardrobe of the web. It controls how content looks — colors, fonts, spacing, layout, animation and responsiveness.

Why it matters

  • Design & branding: colors, typography and spacing bring a page to life.
  • Layouts: Flexbox & Grid arrange elements on any screen size.
  • Responsive: media queries adapt from phones to desktops.
  • Motion: transitions & keyframes add smooth animation — like this whole page!
/* Style an element */
h1 {
  color: #e34c26;
  font-size: 3rem;
  text-align: center;
  transition: all 0.3s ease;
}
JS

JavaScript Behavior

JavaScript is the brain of the web. It controls what happens — interactivity, logic, data, and dynamic updates without reloading the page.

Why it matters

  • Interactivity: respond to clicks, typing, scrolling and more.
  • Logic: variables, conditions, loops and functions power real apps.
  • The DOM: read and change HTML/CSS live in the browser.
  • Everywhere: runs in browsers, servers (Node.js), and mobile apps.
// React to a button click
const btn = document.querySelector("button");
btn.addEventListener("click", () => {
  alert("You clicked me!");
});
